# Student Management System

A beginner-level command-line project built using Python. It supports adding, viewing, searching, updating, and deleting student records. Student data is saved in a local JSON file.

## Requirements
- Python 3.8 or newer
- Terminal or Visual Studio Code
- No external packages required

## Files
- `main.py`: application menu and user interaction
- `student_manager.py`: functions for student record operations
- `students.json`: local data storage
- `.gitignore`: ignores temporary Python files

## Run
Open a terminal in this folder and run:

Windows:
```bash
python main.py
```

macOS/Linux:
```bash
python3 main.py
```

## GitHub
Create a GitHub repository, then run these commands from this folder:
```bash
git init
git add .
git commit -m "Add Student Management System"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/Student-Management-System.git
git push -u origin main
```
Replace `YOUR-USERNAME` with your GitHub username.

## Concepts
Python functions, loops, conditions, dictionaries, lists, JSON file handling, input/output, and CRUD operations.

Use fictional sample student details for demonstrations. Do not publish real students' personal information.
